Frontend & Backend
프론트엔드 / 백엔드
Frontend — UI / 사용자 경험
Flutter Material Design 3 StatefulWidget 기반 반응형 UI. 한국어 최적화 레이아웃.
4단계 피드백 메시지 90 / 70 / 50점 기준 구간별 한국어 피드백 + 효과음.
Backend — 음성 처리 / 채점
speech_to_text (ko_KR) 기기 내장 STT 엔진 사용. 서버 없이 로컬 처리. 실시간 인식.
flutter_tts 한국어 TTS 엔진으로 방언 문장 발음 재생. 속도/피치 조절 가능.
Levenshtein Distance 알고리즘 순수 Dart 구현. 문자열 편집 거리로 발음 유사도 0~100점 산출.
로컬 내장 데이터베이스 서버 불필요. dialect_data.dart에 6지역 × 15문장 정적 관리.
Tech Decisions
왜 이 기술을 선택했나
FrameworkFlutter
iOS · Android · Web 단일 코드베이스. Dart 언어로 음성 처리 로직과 UI를 분리 없이 관리 가능. 빠른 프로토타이핑에 최적.
크로스플랫폼
STT Packagespeech_to_text
서버 없이 기기 내장 STT 엔진 활용. API 키 불필요, 비용 없음. ko_KR 한국어 인식 지원. 오프라인 동작 가능.
서버리스
AlgorithmLevenshtein
두 문자열의 최소 편집 거리를 계산. 방언 특유의 어미 변형을 글자 단위로 비교해 정확한 유사도 산출. 순수 Dart로 외부 의존 없이 구현.
O(m×n)
AI ToolClaude Code
전체 개발 과정에서 AI Agent 활용. 음성 인식 로직, 채점 알고리즘, UI 컴포넌트 모두 Claude Code로 구현 후 직접 코드 검토.
